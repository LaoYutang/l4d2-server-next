# 授权码管理

管理员通过导航中的“系统与安全 → 授权码管理”进入独立页面，创建和管理访问授权，也可配置登录页的自助领取通道。

## 创建和登录

- 默认随机生成 32 位字母数字授权码。
- 支持自定义 8–32 位授权码，可包含英文字母、数字和可见英文符号，不能包含空格或其他空白，区分大小写。
- 自定义码不能与管理员密码、已保留的其他授权码重复，已过期或已撤销但未删除的码也占用该值。
- 可填写备注、选择权限类型、指定到期时间；默认有效期为 1 小时，可选择任意未来日期。
- 完整授权码仅在创建成功时显示，请立即复制保存。列表只显示部分字符，之后无法找回完整码。

登录时直接在密码输入框填写管理员密码或授权码。客户端保存并发送原授权码作为 Bearer 凭证，服务器每次请求都会检查授权记录，不再生成额外的 JWT 登录凭证。

| 权限类型 | 登录身份与用途 |
| --- | --- |
| 临时权限 | 访客，以查看为主，沿用原访客权限；不能执行插件启停、删除、保存配置、新增管理员等敏感操作。 |
| 仅地图上传与下载 | 进入独立的地图上传与下载页面，支持分片上传、查询和取消自己的上传任务、添加地图下载任务、解析链接及地图热重载；只能查看、取消、重试和清理当前授权码创建的下载任务，下载设置和热重载命令只能由管理员配置。 |

原“仅地图上传”授权码也会获得上述下载能力，无需重新创建；授权记录的权限类型保持兼容。

## 查询和管理

列表记录授权 ID、备注、权限、来源、授权时间、到期时间、撤销时间、首次和最近登录时间、登录次数及最近登录 IP。可按备注或 ID 搜索，并按状态、来源筛选，支持分页。

| 操作 | 结果 |
| --- | --- |
| 编辑 | 所有授权记录都可以修改备注和到期时间，包括自助领取、已过期、已撤销记录。可以缩短或延长有效期，没有 30 天上限。 |
| 过期后续期 | 未撤销的授权码更新到未来日期后，原授权码重新有效。 |
| 撤销 | 立即失效并保留记录。之后更新到期时间也不会恢复授权。 |
| 删除 | 立即失效并移除授权记录；操作审计保留。 |
| 清理过期 | 删除服务器当前已到期的全部记录，包括已撤销且已过期的记录；不受当前筛选条件影响。确认后显示实际删除数量。 |

删除后可以重新创建相同的自定义码，此时属于新的授权记录，原始字符串也会再次有效；原记录所属的上传任务和地图下载任务不会转移给新记录。

到期时间由服务器判断。页面使用本地时区显示和编辑日期。撤销、删除或到期后，后续请求会被拒绝，正在查看的日志流会关闭。分片上传任务绑定授权 ID；合并安装前会再次检查授权，其他授权码不能接管任务，管理员可以管理所有任务。升级前未绑定身份的上传任务仅管理员可以管理。

独立页面与“地图管理”复用下载任务组件，支持直接链接批量添加、Steam 工坊链接或合集、工坊 ID 和 QQ 闪传解析。该权限创建的下载任务绑定授权 ID，排队开始下载前和下载文件安装前都会再次检查授权；授权失效时任务失败，不会安装地图。离开页面不会取消已经添加的后台下载任务。

## 自助授权

在本页面开启自助授权后，访客可以在登录页领取 32 位随机码，有效期为 1 小时，权限为普通临时权限。领取后进入 1 小时全局冷却，任何人都需要等待冷却结束才能再次领取。

自助授权和管理员创建的授权码显示在同一列表，都可以续期、撤销、删除和清理。手动创建不受冷却限制；关闭通道、重启管理器或删除记录不会重置冷却。

## 升级与持久化

升级到此授权机制后，原 JWT 授权码全部失效，无兼容或迁移。管理员密码不变，请使用管理员密码登录并重新发放授权码。

新授权记录保存在 `data/auth.db`，服务器使用 `data/auth.key` 计算授权码指纹，不保存完整授权码。迁移时停机复制整个 `data/` 目录，必须同时保留这两个文件。数据库存在而密钥丢失或损坏时，授权码服务不会自动生成新密钥；管理员仍可使用密码登录。

创建、修改、撤销、删除和清理均记录操作审计；授权用户的操作附带授权 ID 和备注。审计不记录完整授权码，删除授权记录不会删除审计历史。
