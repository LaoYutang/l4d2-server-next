# 系统管理

“系统管理”维护面板级别的开关和系统信息。授权码创建、续期、撤销和自助授权开关已移到独立的[授权码管理](/features/auth-codes)页面。

## 玩家在线统计

开启后，管理器每 10 分钟采集一次当前玩家列表，数据滚动保留最近 30 天。统计结果在“玩家统计”页面查看。

关闭后不会新增采样数据，已有数据仍按保留周期滚动清理。

## 监控历史

开启后，性能监控会写入历史数据，可查看 1 小时、24 小时和 3 天趋势。历史数据保存在：

```text
data/monitor.db
```

## 地图资源设置

这里的开关和参数作用于地图上传与下载流程，只有管理员可见。

- **地图自动精简**：开启后，新上传或新下载的地图会在安装前尝试移除服务端不需要的客户端资源。详细规则见 [地图资源精简](/operations/map-trim)。
- **磁盘使用率上限**：默认 90%，可配置 80% - 99%，作用于地图目录所在分区。超过上限时新的上传和下载任务会被拒绝；上传任务对管理员提供二次确认（确认后继续并记录审计日志），游客和“仅地图上传与下载”授权码没有确认入口，下载任务一律直接拒绝。详细行为见[上传地图](/features/maps#磁盘空间保护)。
- **地图热重载指令**：配置“热重载地图”通过 RCON 执行的指令。
- **Steam CDN 下载设置**：为创意工坊下载指定 CDN 地址。

## 关于系统

页面会显示当前管理器版本和项目说明，方便确认部署的版本是否符合预期。

## 面板访问控制

面板黑白名单与可信代理在管理员专属的“访问控制”页面配置，不属于“系统管理”的环境变量或普通功能开关。两个部分可独立保存并立即生效；同一页面的“游戏黑名单”通过 RCON 管理游戏服务端原生封禁。详细规则见[访问控制](/features/access-control)。
