# 系统管理

“系统管理”维护面板级别的开关、授权码和系统信息。

## 临时授权码

管理员可以手动生成临时授权码，并设置有效期。授权码登录后是访客身份，适合临时分享只读访问。

访客身份不能执行插件启停、删除、保存配置、新增管理员等敏感操作。

## 自助授权

开启自助授权后，访客可在登录页自行申请 1 小时有效的授权码。冷却是全局的：任何人领取一次后，接下来 1 小时内所有人都无法再次领取，登录页会显示剩余冷却时间。

授权码只在发放瞬间展示一次，页面刷新后无法找回，领取后请立即妥善保存。

管理员手动生成的授权码不受冷却限制，且可以选择更长的有效期。

这个功能适合想临时开放面板查看权限，但不想长期公开管理员密码的场景。自助通道是公开接口，不需要密码即可申请，不使用时建议保持关闭。

## 玩家在线统计

开启后，管理器每 10 分钟采集一次当前玩家列表，数据滚动保留最近 30 天。统计结果在“玩家统计”页面查看。

关闭后不会新增采样数据，已有数据仍按保留周期滚动清理。

## 监控历史

开启后，性能监控会写入历史数据，可查看 1 小时、24 小时和 3 天趋势。历史数据保存在：

```text
data/monitor.db
```

## 地图资源设置

开启“地图自动精简”后，新上传或新下载的地图会在安装前尝试移除服务端不需要的客户端资源。详细规则见 [地图资源精简](/operations/map-trim)。

## 关于系统

页面会显示当前管理器版本和项目说明，方便确认部署的版本是否符合预期。

## 面板访问控制

面板黑白名单与可信代理在管理员专属的“访问控制”页面配置，不属于“系统管理”的环境变量或普通功能开关。两个部分可独立保存并立即生效。详细规则见[面板访问控制](/features/access-control)。
