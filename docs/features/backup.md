# 备份管理

“备份管理”用于保存和恢复服务器配置状态，适合在调整插件、预设、管理员和服务器配置之前做回滚点。

![备份管理](https://images.laoyutang.cn/2026/06/5d415cad3934aed19183589100dd1895.png)

## 备份内容

备份包含：

- 当前启用插件列表。
- SM/MIX 已修改的 CVAR 配置。
- 已启用 NUT 插件可识别的外部文本配置全文（CFG、所属 EMS 范围内的文本配置），包括编码、BOM 和换行信息。
- SourceMod 管理员列表，包括明确为空的列表。
- 服务器名、公告（`motd.txt`）和服务器信息/描述（`host.txt`）的完整内容，包括空内容。
- 服务器配置。

备份不包含：

- 地图文件。
- 插件文件本身。
- 完整游戏目录。
- 监控数据库。
- 玩家统计数据库。
- 授权数据库 `auth.db` 和授权指纹密钥 `auth.key`。
- 操作审计数据库 `audit.db`。

## 页面操作

备份管理支持：

- 新建备份。
- 查看备份详情。
- 还原备份。
- 重命名备份。
- 删除备份。
- 导出单个备份 YAML。
- 导出全部备份 YAML。
- 导入备份 YAML。

新建、还原、重命名、删除、导入和导出操作仅限管理员。访客查看备份中的服务器配置时，Steam 组 ID 会由服务端替换为固定掩码。

NUT 配置在 YAML 中使用可选的 `text_configs` 字段，旧备份没有该字段时仍可正常导入和还原。管理员在插件备份详情中可查看文本配置全文，访客无法取得这些文本内容。超出文本编辑范围的二进制文件不属于文本配置备份；发现不可读取或过大的候选配置时，创建备份会报错，避免遗漏配置。

## 还原注意事项

还原备份会重置当前插件启用状态、管理员列表、服务器信息和服务器配置。

新备份会明确记录空服务器信息和空管理员列表；对应文件不存在时按空内容或空列表记录。还原时空值会清空现有内容，避免和备份后的修改混合；目标文件或目录不存在时会创建。相关文件读取失败会阻止创建备份，写入失败会返回还原错误。

旧备份完全没有 `server_info` 或 `admins` 时，会保留对应的现有内容。旧备份包含 `server_info` 时，其中省略的字段按空内容还原；明确的 `admins: []` 会清空管理员列表。旧格式省略的空管理员列表无法与未备份管理员区分，因此没有 `admins` 的旧备份不会清空管理员。

如果备份中记录的某些插件在新服务器上不存在，还原时会跳过这些插件并给出提示。迁移服务器时建议配合“插件管理”的“导出所有插件”一起使用。

还原完成后请重启 L4D2 服务器，让插件启用状态和配置文件完全生效。

还原 NUT 时先启用插件、部署默认文件，再按备份写入所属的配置路径，保留备份中的编码与换行格式。还原前会检查文本配置归属和内容格式；不会允许通过备份写入其他插件或游戏目录以外的文件。旧备份没有 NUT 文本配置时，服务器已有的 NUT 外部配置会继续保留。
