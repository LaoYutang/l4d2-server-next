# 备份管理

“备份管理”用于保存和恢复服务器配置状态，适合在调整插件、预设、管理员和服务器配置之前做回滚点。

![备份管理](https://images.laoyutang.cn/2026/06/5d415cad3934aed19183589100dd1895.png)

## 备份内容

备份包含：

- 当前启用插件列表。
- 已修改的插件配置。
- SourceMod 管理员列表。
- 服务器信息。
- 服务器配置。

备份不包含：

- 地图文件。
- 插件文件本身。
- 完整游戏目录。
- 监控数据库。
- 玩家统计数据库。
- 登录密钥 `private.key`。

## 页面操作

备份管理支持：

- 新建备份。
- 查看备份详情。
- 还原备份。
- 重命名备份。
- 删除备份。
- 导出单个备份 YAML。
- 导出全部备份 YAML。
- 导入备份 YAML。

## 还原注意事项

还原备份会重置当前插件启用状态、管理员列表、服务器信息和服务器配置。

如果备份中记录的某些插件在新服务器上不存在，还原时会跳过这些插件并给出提示。迁移服务器时建议配合“插件管理”的“导出所有插件”一起使用。

还原完成后请重启 L4D2 服务器，让插件启用状态和配置文件完全生效。
