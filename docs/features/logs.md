# 日志查看

“日志查看”用于浏览 SourceMod 日志、错误日志和其他日志文件，适合排查插件加载失败、配置错误和运行时报错。

![日志](https://images.laoyutang.cn/2026/06/c615c0f4b867aff609cf3c02842952be.png)

## 日志分类

页面会列出 SourceMod 日志目录中的文件，并按类型区分：

- 运行日志。
- 错误日志。
- 其他日志。

优先查看错误日志，通常能最快定位插件缺少依赖、gamedata 不匹配或配置语法错误等问题。

## 实时推送

选择日志文件后，页面会展示当前内容，并通过实时推送持续接收新增日志行。

实时日志适合配合这些操作使用：

- 启用或禁用插件。
- RCON 控制台执行命令。
- 切换地图。
- 修改插件配置后重载插件。
- 玩家进入服务器触发插件逻辑。

## 清空显示与删除日志

日志工具栏中的“清空显示”只会清除当前浏览器已经加载的内容，不会修改服务器上的日志文件。重新选择文件后，页面仍会读取文件中的最近内容。

管理员可以永久删除历史日志：

- 选择一个历史日志后，使用“删除文件”删除当前文件。
- 使用日志文件列表右上角的“清理”，按运行日志、错误日志或其他日志批量清理。
- 批量清理支持删除 7 天、30 天、90 天以前或全部历史日志，并会在确认前显示文件数量和预计释放空间。

删除操作无法恢复。临时授权用户只能查看日志，不会看到删除和清理入口。

为了避免影响 SourceMod 正在写入的文件，以下日志会被强制保留：

- 文件名日期为今天或未来的标准运行日志、错误日志。
- 最近 10 分钟内仍有更新的任意 `.log` 文件。

标准的 `LyyyyMMdd.log` 和 `errors_yyyyMMdd.log` 会同时参考文件名日期与文件最后修改时间，并采用较新的时间判断是否达到清理期限。其他命名的 `.log` 文件按最后修改时间判断；`.txt` 等非日志扩展名不会被清理。

## 排查建议

常见排查顺序：

1. 在“插件管理”确认插件是否启用。
2. 在“RCON 控制台”执行 `sm plugins list` 查看 SourceMod 加载状态。
3. 在“日志查看”打开错误日志，查找插件名或 `error`。
4. 如果修改了配置，换图或重启服务器后再观察日志。
