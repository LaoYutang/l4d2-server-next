# 日志查看

“日志查看”用于浏览 SourceMod 日志、错误日志和其他日志文件，适合排查插件加载失败、配置错误和运行时报错。

![日志](https://images.laoyutang.cn/2026/06/c615c0f4b867aff609cf3c02842952be.png)

## 日志分类

页面会列出 SourceMod 日志目录中的文件，并按类型区分：

- 运行日志。
- 错误日志。
- 其他日志。

优先查看错误日志，通常能最快定位插件缺少依赖、gamedata 不匹配或配置语法错误等问题。

## 实时推送

选择日志文件后，页面会展示当前内容，并通过实时推送持续接收新增日志行。

实时日志适合配合这些操作使用：

- 启用或禁用插件。
- RCON 控制台执行命令。
- 切换地图。
- 修改插件配置后重载插件。
- 玩家进入服务器触发插件逻辑。

## 排查建议

常见排查顺序：

1. 在“插件管理”确认插件是否启用。
2. 在“RCON 控制台”执行 `sm plugins list` 查看 SourceMod 加载状态。
3. 在“日志查看”打开错误日志，查找插件名或 `error`。
4. 如果修改了配置，换图或重启服务器后再观察日志。
