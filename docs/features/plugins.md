# 插件管理

“插件管理”用于管理 SourceMod/Metamod 插件资源。面板把插件库目录和游戏目录分开管理，启用插件时再复制到 `left4dead2` 中。

![插件管理](https://images.laoyutang.cn/2026/06/3dbe0462012ca01b6971e6744655da95.png)

## 已启用插件

已启用列表展示当前正在应用到服务器的插件。管理员可以：

- 禁用单个插件。
- 禁用并立即卸载 `.smx`。
- 批量禁用。
- 查看插件 README。
- 打开可识别的 CVAR 配置项。

“立即卸载”依赖 SourceMod 能正常响应，个别插件仍可能需要重启游戏服后完全释放。

## 立即加载与立即卸载

普通的启用/禁用只复制或删除插件文件，需要重启服务器或换图后才会生效。“启用并立即加载 smx”和“禁用并立即卸载 smx”在文件操作之外，还会通过 RCON 执行 SourceMod 命令 `sm plugins load` / `sm plugins unload`，让 `.smx` 在运行中的服务器上立即生效，无需重启。

在每行“启用/禁用”按钮旁的下拉箭头中选择对应操作即可。需要注意：

- 仅适用于包含 `.smx` 文件的插件，不含 `.smx` 的插件请使用普通启用/禁用。
- 执行失败时会自动回滚：撤销已加载的 smx 并还原插件文件状态。

## 未启用插件

未启用列表展示插件库中尚未应用的插件。管理员可以：

- 启用单个插件。
- 启用并立即加载 `.smx`。
- 批量启用。
- 删除插件。
- 上传新的插件 ZIP。
- 打开插件商店安装远程插件。

## 插件配置

如果插件包含 `left4dead2/cfg/sourcemod/*.cfg`，面板会尝试识别其中的 SourceMod CVAR 项，展示当前值、默认值和说明，并支持在线保存。

保存配置后，建议按插件说明决定是否需要重载插件、换图或重启服务器。

## 插件预设

预设来自 `backend/preset.yaml`。应用预设会重置当前插件启用状态，并按预设启用指定插件和配置项。适合在“纯净服、多特、肉鸽、娱乐服”等不同玩法之间快速切换。

应用预设前建议先创建一次备份，避免覆盖现有配置后难以回退。

## 插件商店

![插件商店](https://images.laoyutang.cn/2026/06/8e3947cb21cb449eced9d53745468564.png)

插件商店可浏览、搜索和安装远程插件库中的插件，默认插件库为：

```text
https://github.com/LaoYutang/l4d2-plugins-store
```

商店支持：

- 配置 GitHub 代理。
- 配置 GitHub Token，提高 API 限额并访问自定义公开仓库。
- 指定自定义公开插件仓库，仓库结构需为每个插件一个目录，分支固定为 `master`。

## 导出插件

“导出所有插件”会把插件库打包为 ZIP，适合迁移或备份。导出期间会占用服务器 CPU 和网络带宽，建议避开游戏高峰期。

插件 ZIP 的目录规范见 [插件 ZIP 规范](/operations/plugin-package)。
