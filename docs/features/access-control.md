# 面板访问控制

“访问控制”仅对管理员显示，用于限制 Web 管理面板访问，不会修改 L4D2 玩家封禁或 SourceMod 配置。规则会保护登录页、静态资源和全部管理接口。

## 面板黑白名单

面板黑名单优先于面板白名单：命中任意黑名单规则会立即拒绝；白名单为空时不限制，白名单存在启用规则时必须至少命中一条。

规则支持三种格式：

- 地区关键字：对 ip2region 原始结果进行包含匹配，例如 `中国`、`广东`、`电信`。
- 单 IP：例如 `203.0.113.10` 或 `2001:db8::10`。
- CIDR：例如 `192.168.1.0/24` 或 `2001:db8::/32`。

普通局域网地址不会自动放行。如需允许局域网管理员，请显式添加相应 CIDR 白名单。`127.0.0.0/8` 和 `::1` 始终允许，供服务器本机恢复配置。

保存启用状态的规则前，服务端会使用新规则检查当前管理员。当前 IP 在黑名单中，或未命中非空白名单时，保存会被拒绝且旧配置继续生效。

## 可信代理

可信代理决定是否接受请求中的真实 IP 转发头。TCP 对端不在可信代理列表时，管理器会忽略 `X-Forwarded-For` 和 `X-Real-IP`，直接使用连接来源地址。

TCP 对端可信时，管理器优先从右向左解析 `X-Forwarded-For`，跳过可信代理节点并取得第一个不可信地址；没有该头时才使用 `X-Real-IP`。格式错误的转发头会被拒绝。

首次配置默认信任：

```text
127.0.0.0/8
::1/128
```

可信代理支持单 IP 和 CIDR，但禁止 `0.0.0.0/0` 与 `::/0`。页面会展示 TCP 对端、转发头、最终客户端 IP 和命中的代理规则，保存前应先确认诊断结果符合实际链路。

## 配置与恢复

配置保存在 `data/access_control.json`，两个 Tab 独立保存并立即生效。文件不存在时面板黑白名单默认关闭；显式清空可信代理后，重启也会保持为空。

配置损坏时只允许 TCP 直连回环地址访问。管理员可在服务器本机打开面板并保存有效配置，或停止服务后手工修复文件。
