# 服务器状态

“服务器状态”是登录后的首页，用来确认游戏服是否在线、当前地图和玩家情况是否正常。

![首页](https://images.laoyutang.cn/2026/06/99465f674d128e3a406d294753147479.png)

## 导航菜单

桌面和手机使用相同的菜单顺序。服务器状态、地图管理、插件管理和 RCON 控制台为常用入口，其余页面按功能分组：

- **运行数据**：性能监控、玩家统计、日志查看。
- **服务器设置**：服务器信息、服务器配置、备份管理。
- **系统与安全**：管理员设置、授权码管理、访问控制、操作审计、系统管理。其中授权码管理、访问控制和操作审计仅管理员可见。

分组可以分别展开或收起，浏览器会记住展开状态。进入分组内的页面时，所属分组自动展开并高亮当前入口。桌面收起侧栏后，可通过分组图标打开二级菜单。

窗口高度不足时，仅菜单区域滚动；顶部标识和底部的主题切换、退出登录、桌面侧栏展开/收起按钮始终保留。手机可通过顶部菜单按钮打开导航，点击右上角关闭按钮、遮罩或选择页面后关闭导航。菜单支持亮色、深色主题和手机底部安全区。

## 状态卡片

首页会通过 RCON 读取并展示：

- 服务器名称。
- 当前地图和可识别的地图真实名称。
- 游戏难度。
- 游戏模式。
- 在线玩家数量。

如果这些信息为空或读取失败，优先检查 `L4D2_RCON_URL`、`L4D2_RCON_PASSWORD` 和游戏服 `server.cfg`。

## 在线玩家列表

玩家列表包含昵称、SteamID、IP/地区、Ping、丢包、连接时长等信息。管理员可直接执行：

- 复制 SteamID。
- 查询玩家 Steam 账号中的 L4D2 游戏时长。
- 将玩家加入 SourceMod 管理员列表。
- 踢出玩家。
- 永久封禁 SteamID。

查询 Steam 游戏时长需要配置 `STEAM_API_KEY`。这是首页玩家列表的外部 Steam 数据查询，和“玩家统计”页面里基于本服务器采样估算的在线时长不是同一个东西。

## 快捷操作

首页提供常用运维操作：

- 重启服务器。
- 选择官方或第三方地图并切换。
- 临时设置最大玩家数。
- 调整游戏难度。
- 调整游戏模式。

> 临时最大人数通常需要多人破解插件支持，并且重启后会失效；需要长期生效时，请写入服务器配置或使用对应人数管理插件。
