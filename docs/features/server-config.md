# 服务器配置

“服务器配置”面向 `server.cfg` 中的常用参数，适合维护服务器可见性、匹配连接和自定义配置行。

![服务器配置](https://images.laoyutang.cn/2026/06/c68bf9754dc2ae42d88355499956121d.png)

## 常用开关

页面支持：

- 隐藏服务器：对应 `sv_tags hidden`。
- 仅匹配连接：限制连接来源。
- Steam 组 ID：配置服务器关联的 Steam 组。该值仅管理员可见，访客接口只返回固定掩码。

基础设置右上角的“查看文本”会展示当前活动 `server.cfg` 中由 Tick 模板等来源维护的固定部分。该窗口只读，不包含面板管理的三个常用设置和自定义区域；`rcon_password`、`sv_password` 等密码值会在服务端统一替换为掩码，管理员和访客均无法通过该窗口读取原值。

## 自定义配置

每一项自定义配置由“注释”和“配置指令”组成。注释可以为空，也可以填写多行；保存到文件时会统一写在对应指令上方：

```text
// 关闭一致性检查
// 允许玩家使用不同的本地资源
sv_consistency 0
```

指令后方的行内注释也会在保存时自动移动到上方。例如：

```text
sm_cvar example_value 1 // 示例说明
```

保存后会规范化为：

```text
// 示例说明
sm_cvar example_value 1
```

位于引号外的 `//` 会识别为行内注释，即使前面没有空格也可以，例如 `"26"//伤害说明`。引号内的文本以及 `http://`、`https://` 等 URL（包括路径中的 `//`）不会被错误拆分。连续注释始终归属于其后的第一条指令；文件末尾只有注释而没有对应指令时，页面会阻止保存并提示修复。

可以通过单项“编辑”分别修改注释和指令，也可以点击右上角“文本编辑”批量修改整个自定义区域。文本弹框的“应用到页面”只更新当前页面草稿，仍需点击页面右上角“保存修改”才会写入当前 `server.cfg` 和现有 Tick 模板。

自定义参数标题旁的搜索框可以按指令或注释实时筛选条目；搜索只影响页面展示，不会修改或删除配置。

长期配置建议写在这里或直接维护 Tick 模板，不要只在 RCON 控制台临时执行。直接修改活动 `server.cfg` 的固定部分可能在游戏容器下次启动时被 Tick 模板覆盖。

## 权限与生效

访客登录时只能查看，管理员登录后才能保存。Steam 组 ID 属于敏感配置：管理员可以读取原值，访客页面及备份详情只会显示固定掩码，不会把真实 ID 发送到浏览器。

保存后通常需要重启服务器或换图才会完全生效。访客可以查看脱敏后的固定文本、注释和指令，但不能应用草稿或修改配置。
