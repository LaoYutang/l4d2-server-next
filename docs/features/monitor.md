# 性能监控

“性能监控”展示服务器资源使用情况，包括 CPU、内存、网络和硬盘。

![性能监控](https://images.laoyutang.cn/2026/06/2868050dbad60124dcb313a23d422685.png)

## 实时监控

实时视图会持续刷新当前资源占用，适合判断：

- 地图或插件是否导致 CPU 飙升。
- 内存是否持续增长。
- 上传、下载或导出插件时的网络吞吐。
- 磁盘剩余空间是否足够安装地图和插件。

Docker 部署时，管理器通常需要挂载 `/proc:/host/proc:ro` 才能读取宿主机进程和系统指标。

## 历史趋势

开启监控历史后，可以查看实时、1 小时、24 小时和 3 天趋势。历史数据写入：

```text
data/monitor.db
```

如果只需要轻量管理器，或者磁盘写入比较敏感，可以在“系统管理”中关闭监控历史。

## 和玩家统计的区别

性能监控记录机器资源；玩家统计记录玩家在线采样。两者分别存储在不同数据库中：

- `data/monitor.db`
- `data/player_stats.db`
