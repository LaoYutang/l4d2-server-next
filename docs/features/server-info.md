# 服务器信息

“服务器信息”用于编辑游戏服务器对外展示的名称、信息页和公告内容。

![服务器信息](https://images.laoyutang.cn/2026/06/5929ea251d7de6ba9846d2ec90fbc095.png)

## 可编辑内容

页面包含三块内容：

- 服务器名：写入 `l4d2_hostname.txt`。
- 服务器信息：写入 `host.txt`。
- 服务器公告：写入 `motd.txt`。

这些文件会被游戏服务器读取，用于展示服务器名称、信息页和 MOTD 公告。

## 权限

访客登录时只能查看内容，管理员登录后才能保存修改。

## 生效方式

保存后，如果游戏内没有立即刷新，建议换图或重启服务器。部分客户端可能也会缓存 MOTD 或信息页内容。
