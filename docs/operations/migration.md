# 备份迁移流程

迁移服务器时建议同时导出“备份文件”和“插件文件”。备份文件保存配置状态，插件文件保存插件资源，两者配套使用最稳妥。

## 旧服务器导出

1. 进入“备份管理”，点击“新建备份”，输入容易识别的名称，例如 `迁移前备份`。
2. 在备份列表中点击单个备份的“导出”，下载该备份的 `.yaml` 文件。
3. 如果要一次导出全部备份，点击“全部导出”，下载 `backups_all.yaml`。
4. 进入“插件管理”，点击“导出所有插件”，等待压缩完成后下载 `plugins_all.zip`。

导出插件时会占用服务器 CPU 和带宽，建议避开游戏高峰期。

## 新服务器导入

1. 部署并启动新服务器和管理器。
2. 确认 `L4D2_GAME_PATH`、`L4D2_RCON_URL`、`L4D2_RCON_PASSWORD` 等配置正确。
3. 进入新服务器“插件管理”，上传旧服务器导出的 `plugins_all.zip`。
4. 进入“备份管理”，点击“导入”，选择旧服务器导出的 `.yaml` 或 `backups_all.yaml`。
5. 如果导入的备份名称已存在，系统会自动追加 `(1)`、`(2)` 等后缀。
6. 在备份列表中选择目标备份，点击“还原”。
7. 还原完成后重启 L4D2 服务器。

## 迁移范围

备份文件包含：

- 启用插件列表。
- 插件配置修改。
- 管理员列表。
- 服务器信息。
- 服务器配置。

备份文件不包含：

- 地图文件。
- 插件文件本身。
- 完整游戏目录。
- 监控数据库。
- 玩家统计数据库。
- 登录密钥 `private.key`。

地图和完整游戏目录请按实际部署方式单独复制或重新安装。
