# 地图资源精简

地图资源精简会把客户端才需要的资源从服务端 VPK 中移除，适合磁盘空间紧张或地图包体积很大的服务器。

## 使用方式

在“系统管理 → 地图资源设置”中开启“地图自动精简”后，新上传或新下载的地图会在安装前尝试精简。

已经上传的地图可以在“地图管理”列表中点击单个地图的“精简”按钮手动处理。

## 会移除的资源

典型会移除：

- 地图源文件：`.vmf`、`.vmx`。
- 材质贴图：`materials/*.vtf`。
- 声音：`sound/` 或 `sounds/` 下的 `.mp3`、`.wav`。
- 部分客户端模型数据：`models/*.vvd`、`models/*.vtx`。

如果地图格式暂不支持精简，面板会保留原文件继续安装。

## 注意事项

- 精简后的 VPK 只适合服务端使用，不适合给玩家作为客户端地图包安装。
- 当前主要支持 VPK v1 单文件地图包。
- 多分卷或特殊布局的 VPK 会自动跳过精简。
- 如果你还需要对外分发原始地图文件，请单独保留未精简版本。
- 首次启用自动精简前，建议先对一张地图手动测试。
